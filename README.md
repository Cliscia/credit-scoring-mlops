# Credit Scoring with MLOps

An end-to-end Machine Learning project that simulates a real-world credit risk assessment pipeline, from data ingestion to model deployment and monitoring.

---

## Business Problem

Financial institutions must decide whether to approve or reject a loan application.

Approving a high-risk applicant may result in financial losses, while rejecting a reliable customer represents a missed business opportunity.

This project develops a Machine Learning pipeline capable of estimating the probability of customer default, supporting credit analysts in making more informed decisions.

---

## Project Objectives

- Predict the probability of customer default.
- Compare baseline and advanced Machine Learning models.
- Optimize the decision threshold according to business costs.
- Build an end-to-end MLOps pipeline.
- Deploy the model as a REST API.
- Monitor model performance after deployment.
